# 兼容与验证状态

版本：0.1.0，API 文档核对日期：2026-11-18。

| 部分 | 状态 | 含义 |
|---|---|---|
| Agent Skills 核心格式 | 按公开标准编写、静态校验 | 不等于所有宿主行为已验证 |
| Codex / Claude Code / Cursor / Gemini CLI 路径 | 官方文档支持 | 待在对应应用安装验收 |
| 本地归档 helper | Node.js 自动测试 | 覆盖选择确认、重复归档、历史保留、路径、锁、检索与重建 |
| Harness 工具适配层 | 合约测试 | 覆盖会话隔离、过期/目录变化拒绝、确认后写入 |
| Harness 插件真实加载 | 待验证 | 当前环境没有 dsh，SDK 下载不可用，不能声称联调通过 |
| 每日联网研究效果 | 待使用者验收 | 依赖宿主搜索及来源获取能力 |
| 原生定时任务 | 尚未启用 | 第一版提供提示词和配置指南，由宿主调度 |

Harness 基于官方 0.2.2 系列工具、技能注册和 bundle API 编写，兼容范围限定为 >=0.2.2-rc.3 <0.2.3。清单声明只代表目标范围，不代表每个版本都已实测。

验收建议：加载 skill/插件；设置一个测试目录；手动研究；选择一条测试信息归档；重启后检索；模拟升级确认资料保留；最后验证一次实际定时运行。不要用未经过这些步骤的预览包替代生产验收。

# 换电脑、升级与迭代

## 个人数据

每人保存自己的知识库，位置由自己选择。helper 的个人配置默认 `~/.game-ai-digest/config.json`；可通过 GAME_AI_DIGEST_CONFIG 指向其他绝对位置。插件 archiveRoot 配置也可指定目录。知识库内部卡片路径是相对路径。

## 换电脑或换 Agent

1. 备份知识库与个人配置，记录所用版本。
2. 在新电脑安装并登录所选 Agent，下载同一版本或经验证的新版本。
3. 安装对应 skill/插件，将知识库复制到你选择的位置。
4. 指定新的绝对归档路径，检查读写并检索一条旧卡片。不要复制旧账号凭据。
5. 检查原有定时任务和旧电脑是否还在运行，按需迁移；避免重复运行。云端任务和本地任务分别检查。

## 提出迭代

提供仓库链接、版本/分支以及预期变化。例如：“基于 v0.1.0，美术与动作消息提高优先级，添加接入成本字段；先给方案，确认后实施并上传。”维护 Agent 应先读取当前仓库和个人数据格式，给出范围、验证方式、升级影响，等待确认后编写代码。历史讨论不能替代读取当前版本。

实现后记录版本和改动，运行相应检查，构建 skill ZIP 与 Harness TGZ。更新不更改个人偏好，不覆盖已归档卡片。数据格式变更应先备份、提供迁移方案和恢复路径。用户未要求时不发布新版本、不修改仓库可见性、不启用调度。

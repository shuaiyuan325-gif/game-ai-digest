# 开始使用

先安装你偏好的 Agent，登录自己的账号并确认有联网研究和本地文件能力。解压通用 skill 包，在 Agent 中打开这个文件夹，发送：

> 请读取 docs/install.md，按我当前使用的 Agent 安装 game-ai-digest。我的归档目录是【填写自己的绝对路径】。检查技能加载、联网搜索、来源打开和目录读写，列出哪些已通过、哪些不可用。先生成一份真实日报，不归档，也不开启定时任务。

Agent 无法读取文件时，可上传 SKILL.md 及对应 references；这只是手动加载说明，不能保证原生安装或本地归档。无法联网/写入时需要宿主提供相应能力。

常用指令：
- 生成今天的游戏 AI 日报。
- 归档今天的具体条目，并加上这条备注……
- 查找知识库里与角色一致性有关的工具。
- 把归档目录改为我指定的新位置；先告诉我旧资料如何迁移。
- 按 schedule 说明检查并开启每天北京时间 9 点的日报。不要自动归档。

安装不会开启后台任务。首次初始化只保存个人偏好并检查文件权限，不保存新闻。阅读不等于同意归档。

换电脑前备份：知识库文件夹、个人配置及所用版本号。仅下载原始安装包不会带回后来收录的资料。恢复步骤见 docs/migration.md。
